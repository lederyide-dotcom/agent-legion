# agent-legion 評估：公開版、LLM 後端、「隨口丟想法」的缺口｜2026-11-15

> 依 anti-todo-tw 與 frontier-proposal-tw 整理。所有現況都以指令實際查過；沒查證的標「未驗證」。作者 DavidY-tw。

## 結論

1. **公開版**：還不建議把目前的 repo 直接改成公開。程式本身去敏感化做得好（沒有目標 repo 名稱、沒有機密、git 歷史沒有 token 樣式），但有 4 個阻礙：
   - 歷史 commit 含本名（4 個）。
   - 只有 Windows 啟動腳本。
   - 只支援 Claude Code CLI。
   - 沒有給陌生人的安全說明。

   建議走「乾淨歷史的公開預覽版」。
2. **LLM 後端**：
   - Claude 訂閱今天就能用：legion 呼叫 `claude -p`，登入訂閱的 Claude Code 即可；訂閱用量上限可撐幾個任務未驗證。
   - 地端 LLM 目前不支援（沒有這類後端）。8GB VRAM 能跑的 7～8B 模型做多步工具操作與嚴格 JSON 的穩定度，預期不足（未驗證）。建議只把書記官、摘要等便宜角色交給地端。
3. **隨口丟想法 → 完善計畫 → 自主閉環**：後半段（守門、驗收、審查、熔斷、軍師、晨報、手機頁）已經做到。前半段缺兩個關鍵：
   - **入口太硬**：想法必須是 vault/INBOX 的 .md 檔並寫明 `repo:`，沒寫就熔斷 `no_repo`。
   - **規劃者不會發問**：輸出格式沒有提問欄位，模糊的想法只能硬猜成規格。
