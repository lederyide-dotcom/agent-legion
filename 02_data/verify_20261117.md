## 3. subdir 白名單檢查（David 選 A）

- 做法：`src/legion/intake.py` 的 `validate_subdir(repo, subdir, kind)` 是唯一的檢查，`legion idea`（`subdir_for`）與讀進想法檔（runner）共用。後續想法沿用父任務 subdir，回到 INBOX 時同樣經過檢查。
  - 必須是非空字串、相對路徑（Windows 與 POSIX 的磁碟代號、開頭 / 或 \、網路路徑都擋）。
  - 解析後（含 `..`、捷徑連結、短檔名）仍在 repo 內，且不是 repo 本身；不能是 `.git` 內部；資料夾必須存在。
  - write 任務：repo 要有 commit，資料夾要已進 git（`git --literal-pathspecs ls-tree -d HEAD`，pathspec 語法一律當字面路徑）。
  - 不合格的想法檔不建任務，原因列在 tick 摘要的 `bad_inbox`；壞檔留在 INBOX，改好就會被領取。
- 驗收：
  - `pytest tests/test_idea.py` → 29 passed：20 種拒收輸入（`../x`、`..\x`、`C:x`、UNC、`:(top)pkg`、`.git` 等）、正規化（`pkg/`、`pkg/../pkg`）、readonly 允許沒進 git 的資料夾、讀進想法檔拒收壞 subdir 但照常領取好的、repo 打錯不會讓 tick 崩潰。✅
  - 全套（PowerShell）→ `368 passed in 385.24s`。✅
- 審查（code-reviewer，另做了大小寫、短檔名、尾端點與空白、NTFS 資料流、junction、中文路徑等邊界測試）：
